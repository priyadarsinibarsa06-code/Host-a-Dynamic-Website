# Dynamic Website Project

## Project Description
This is a simple Dynamic Website project created using HTML, CSS, and JavaScript.

The website allows users to:
- Enter their name
- Submit data dynamically
- Display welcome message with current date and time

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Dynamic user interaction
- Responsive design
- Real-time date and time display
- Simple and user-friendly interface

## How to Run the Project
1. Download the project folder
2. Open the folder
3. Run the `index.html` file in browser
